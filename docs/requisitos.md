# Requisitos Funcionais

- RF01 : Cadastrar cinemas
- RF02 : Cadastrar filmes
- RF03 : Cadastrar sessões
- RF04 : Registrar público por sessão
- RF05 : Consultar sessões por cinema
- RF06 : Totalizar público por sessão, filme e cinema
- RF07 : Consultar elenco e diretor de filmes

# Regras de Negócio

- RN01 : Público não excede a capacidade do cinema
- RN02 : Intervalo mínimo de 20 min entre sessões na mesma sala
- RN03 : Filme deve estar ativo para ser exibido
- RN04 : Público é registrado uma vez por sessão
- RN05 : Sessão pertence a um cinema e exibe um filme
